# 操作细节

按项目所处阶段选用，不要求每项文献任务都执行完整设计流程。

## 参考数据

- 保存原始序列、accession.version、分类映射、下载日期、筛选日志、最终 FASTA 与软件/参数版本。
- 目标、近缘非目标和环境背景分开；区分无参考、缺完整结合位点、分类/质量存疑三类缺口。
- 避免数据库条目丰富的物种主导结果。保留合理种内变异，同时报告物种等权和重点谱系结果。
- 检查 PCR 产物参考的末端是否来自合成引物；不能用这种末端证明天然结合位点保守。
- 建立候选各自可评估集和共同可评估集。跨位点无法获得完整共同集时，说明可比性限制。

## 位点与候选

- 比对用于检查同源性、保守侧翼与插入区信息；rRNA 结构可辅助判断，不能代替跨类群验证。
- 可用 ecoPrimers 作无比对候选发现，再以独立数据审查；不强制所有方法先进行多序列比对。
- 对每条参考检查两引物相向结合、完整位点、实际间距和多产物风险；必要时处理环状基因组跨起点。
- 保存错配位置、类型与相邻关系。比较合理的错配模型，不将同样的错配总数视作等效。
- 人工修改发表序列后另建候选 ID，并说明修改位置；新尾序列与新靶向序列分别记录。

## 简并、长度与热力学

- IUPAC 理论变体数为各位置允许碱基数的乘积，F/R 分别计算。等摩尔假设下单变体浓度约为总浓度/变体数，实际合成与反应未必满足该假设。
- 能穷举时检查全部变体；不能时说明抽样或界限方法，特别检查 3′ 组合、加尾全长与交叉二聚体。
- Tm 与二聚体结果保留模型、盐/Mg²⁺、dNTP、寡核苷酸浓度及添加剂条件，避免脱离配方给精确数值。
- 常规非重叠结构中：含靶向引物产物长度 = 插入区 + F 靶向长度 + R 靶向长度；文库长度按建库阶段加入尾部。特殊重叠结构另定义。
- 用真实未比对序列与坐标计算长度分布。双端拼接考虑修剪后的有效读长和所需重叠，不只看平均片段。

## 工具分工

| 工具 | 适合回答的问题 | 使用前核对 |
|---|---|---|
| ecoPrimers | 候选锚点与 barcode 发现 | 版本、数据库格式、长度参数语义 |
| PrimerMiner | 参考代表性与位置/类型相关错配评价 | 物种处理、罚分模型及阈值来源 |
| Primer3 / Primer3Plus | 寡核苷酸候选与化学约束 | 反应条件、靶向部分/尾部和产物定义 |
| ecoPCR / obipcr / Primer-BLAST | 给定模型下的匹配或产物检查 | 是否成对、方向、错配和背景范围 |

ecoPrimers 的 `-l/-L` 指不含引物的 barcode；Primer3 的 `PRIMER_PRODUCT_SIZE_RANGE` 包括靶向引物，但不包括 5′ overhang。不要直接共用长度阈值。[ecoPrimers 选项](https://pythonhosted.org/OBITools/scripts/ecoPrimers.html)；[Primer3 手册](https://primer3.org/manual.html)。工具版本更新后重新核对参数。[ecoPrimers 论文](https://doi.org/10.1093/nar/gkr732)；[PrimerMiner 论文](https://doi.org/10.1111/2041-210X.12687)。

## 多目标选择与实验

- 先定义有依据的硬门槛，再展示 Pareto 候选及取舍；使用加权总分时公开权重与敏感性。
- 数据充分时按物种/谱系留出，而非随机拆 accession；样本稀疏时明确泛化估计有限。
- 组合方案报告相对基准的新增恢复、分类补充和共同盲区；同管方案查竞争，分管方案说明归一化与整合。
- blocker 同时测试目标误阻断、不同背景比例及目标净恢复，避免只是把读段份额转给另一类非目标。
- 组织面板包含预测困难类群；mock 明确平衡的是质量、拷贝还是组织量，并包含稀有目标/高背景挑战。
- 真实 eDNA 设置现场、提取和 PCR 空白、阳性对照及独立重复；先定污染/检出规则，再解释结果。
- 失败时分诊参考缺失、位点失配、分类信息不足、抑制、竞争与分析过滤，再选择补参考、改引物、换位点或调整条件。

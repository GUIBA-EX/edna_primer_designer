# 指标与验证终点

比较前固定目标、参考版本和模型；每项比例同时给绝对数量。以下是建议口径，不替代原论文中同名指标的定义。

## 集合与缺失状态

- T：预先声明的目标物种集合。
- E：T 中具有完整双引物位点和插入区、可评估当前候选的物种。
- H_s：物种 s 保留的可评估参考单倍型；A_s 为其中预测可扩增者。
- B：可评估的非目标物种集合。

记录“预测可扩增 / 预测不满足模型 / 不可评估”三态。分母为零记 NA；属/科级任务统一更换集合阶元。

## 核心指标

| 指标 | 定义 | 解释 |
|---|---|---|
| 参考可评估率 | \|E\| / \|T\| | 数据完备度，不是扩增覆盖 |
| 物种至少一型覆盖 | #{s∈E: \|A_s\|>0} / \|E\| | 乐观覆盖，不代表所有个体 |
| 已观察型稳健覆盖 | #{s∈E: A_s=H_s} / \|E\| | 仅对已观察且可评估的变异 |
| 物种等权单倍型覆盖 | mean_s(\|A_s\|/\|H_s\|), s∈E | 防止多 accession 物种主导 |
| 全目标证据覆盖 | #{s∈E: \|A_s\|>0} / \|T\| | 保留无参考目标，不把未知称为失败 |
| 非目标成对命中率 | B 中预测有产物的物种数 / \|B\| | 不直接预测 reads 比例 |

按重点谱系分层报告。候选之间同时给各自和共同可评估集合的结果，避免缺数据者看似更好。

## 分类信息与联合收益

分别在全部可评估参考和预测扩增集合上计算共享 barcode 冲突组；只看后者可能因漏掉难物种而虚增分辨率。列近缘种、种内变异、分类器/参考库及保守归属阶元。

需要聚类终点时，可参考 Marquina 等的 ETR：S 为当前分析的完整参考物种集合，S_A 为其中有条码扩增的物种，S_U 为其扩增条码仅落入一个且不混入其他物种标签的 cluster 的物种；B_C = |S_A|/|S|，B_E = |S_U|/|S_A|，ETR = |S_U|/|S|。该定义依赖聚类规则；允许多个 ASV 归为同一物种的任务，不应自动把种内多样性视为失败。[原始定义](https://doi.org/10.1111/1755-0998.12942)

组合方案报告全目标上的净增覆盖/可用归属、残余集恢复和共同盲区，不相加单对百分比。

## 验证状态

| 阶段 | 应记录的证据 | 下一步 |
|---|---|---|
| 文献 | 身份、来源、序列/长度定义 | 补齐影响设计的未核事项 |
| 计算 | 参考与参数、成对匹配、分辨率、背景及化学风险 | 选代表性组织和困难类群 |
| 组织 DNA | 产物确认、目标恢复与对照 | 构建混样与竞争条件 |
| Mock | 输入比例、稀有目标、背景/抑制及重复性 | 在匹配环境中验证 |
| 真实 eDNA | 独立重复、完整对照、独立证据与失败条件 | 明确可外推的场景 |

门槛按研究目标和风险预先定义，不设通用成功比例。状态可用 not_started、in_progress、passed_under_conditions、failed、not_evaluable；通过时写明适用条件。
